# Água vezes 10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deixar os volumes de água da base 10 vezes maiores (tanque de 1000 L), com os gastos subindo junto, sem mudar o ritmo do jogo.

**Architecture:** É uma mudança de calibragem: os números moram em `src/config/constants.ts` e o resto do jogo lê de lá. O trabalho é trocar as constantes, achar os poucos litros escritos direto no código, atualizar os testes que fixam valores antigos e a documentação dos números.

**Tech Stack:** TypeScript, Vitest (`npm test`), Next.js (`npm run build`), `npm run typecheck`.

Spec: `docs/superpowers/specs/2026-11-15-act1-story-design.md`, seção "PR 1: água vezes 10". Issues: #407 (ato 1) e o "tanque maior" da #409.

## Global Constraints

- Regra: volumes da base sobem 10 vezes; o que uma pessoa usa de uma vez fica no valor real (`DRINK_AMOUNT_FROM_DISPENSER: 2.0`, `MEAL_WATER_L: 1`).
- A água da eletrólise não muda (`WATER_KG_PER_O2_KG: 36 / 32`, `O2_KG_PER_PERSON_DAY: 0.84`).
- Todo número de balanceamento mora em `src/config/constants.ts`. Nada de número mágico novo.
- Ritmo conferido: os 250 L iniciais duram mais de meio sol e menos de um sol sem gelo novo.
- Custo de energia por hora não pode mudar: o que é "por litro" cai 10 vezes.
- Textos da UI em inglês, sem emoji. Docs em pt-BR.
- Dado real: 30 L por pessoa por sol só vai para o texto do jogo como "real" se houver fonte registrada em `docs/data/numeros-reais.md`; sem fonte, é marcado como escala de jogo.
- Linha de base: `npx vitest run` passa com 1042 testes em `origin/main` @ `b38873f`.
- Commits em Conventional Commits, com `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.

- [ ] **Step 1: Escrever o teste da regra do spec**

Acrescentar em `src/config/balance.test.ts` (ajustando os imports ao que o arquivo já importa):

```ts
describe('água vezes 10 (spec do ato 1)', () => {
  it('o tanque tem 1000 L e começa com um quarto', () => {
    expect(WATER_SYSTEM_CONFIG.MAX_BASE_WATER).toBe(1000);
    expect(WATER_SYSTEM_CONFIG.INITIAL_BASE_WATER).toBe(250);
  });

  it('a parede cheia do abrigo leva centenas de litros e cabe no tanque', () => {
    expect(RADIATION_CONFIG.SHELTER_WALL_MAX_L).toBe(600);
    expect(RADIATION_CONFIG.SHELTER_WALL_MAX_L).toBeLessThan(WATER_SYSTEM_CONFIG.MAX_BASE_WATER);
    expect(RADIATION_CONFIG.SHELTER_WALL_MAX_L * RADIATION_CONFIG.SHELTER_G_CM2_PER_L).toBeCloseTo(10);
  });

  it('uma carga cheia do rover enche metade do tanque', () => {
    expect(WATER_SYSTEM_CONFIG.ICE_CARGO_MAX * WATER_SYSTEM_CONFIG.LITERS_PER_KG_ICE).toBe(WATER_SYSTEM_CONFIG.MAX_BASE_WATER / 2);
  });

  it('o reciclador gasta a mesma energia por hora de antes (0,6 %/h)', () => {
    expect(STATION_CONFIG.WATER_RECYCLE_L_PER_HOUR * UTILITY_CONFIG.RECYCLER_POWER_PER_L).toBeCloseTo(0.6);
  });

  it('o que uma pessoa usa de uma vez continua no valor real', () => {
    expect(WATER_SYSTEM_CONFIG.DRINK_AMOUNT_FROM_DISPENSER).toBe(2);
    expect(UTILITY_CONFIG.MEAL_WATER_L).toBe(1);
  });
});
```
